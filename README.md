# Genz Cafe — Rooftop Ordering Prototype

A static, interactive HTML prototype for demonstrating customer ordering and the restaurant owner dashboard.

## Run locally
Open `index.html` in Chrome or Edge. Internet access is recommended for remote food/hero images.

## Deploy to Vercel with the CLI
1. Install Node.js if it is not already installed.
2. Open a terminal in this folder.
3. Run `npx vercel` and follow the prompts.
4. For a production deployment, run `npx vercel --prod`.

Alternatively, push this folder to a GitHub repository and import that repository at https://vercel.com/new. It is a static site; no build command is needed and the project root is this folder.

## Prototype limitations
- Demo orders are held only in the current browser session; they are not synced between devices or saved to a database.
- WhatsApp messages are previews only. No messages are sent.
- Use fictional customer data in demos.
